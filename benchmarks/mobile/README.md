# Protocolo de benchmark mobile

Registre modelo, Android, RAM, espaço livre e modo avião. Execute cinco vezes cada cenário,
descarte a primeira medição quente apenas quando indicado e publique mediana e pior caso.
`local_ai_optional` e `push_to_talk_optional` não bloqueiam o Core textual. Os budgets são
hipóteses iniciais e só podem virar gates depois de medições no Galaxy J5 Prime alvo.
